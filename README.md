# Jerry Nobles Life Begins

एक author website बनानी है। ठीक है? उसमें चार pages होंगे। ठीक है? Home, About, Contact और मैं दे दे रही हूँ क्या-क्या होंगे। ठीक है? चार pages की website होनी चाहिए। Email, number और book की information और ये सारी चीज़ें मैं तुम्हें भेज रही हूँ और writer की भी information, author की information भी मैं भेज रही हूँ। एक अच्छी चीज़ बताओ, जिससे मैं अपनी website बना सकूँ। ठीक है? तो उसके लिए क्या करना है? तुम्हें क्या चाहिए? ठीक है, author website बनानी है।

अच्छा! देखो, यह जो image मैंने तुम्हें भेजी है, इसमें about information भी है और author की एक book भी है। ठीक है? जैसे एक book है इसकी, उसकी image भी मैंने तुम्हें भेजी है। book के पीछे author के बारे में भी लिखा हुआ है। ठीक है? तो about वाला जो page है, उसके अंदर author के बारे में लिख देना। ठीक है? और books वाला जो page है, उसमें इसकी एक ही book upload कर देना। ठीक है? और contact में उसकी contact information, एक form भी आ जाए। सही है? और home page में सारी चीजें align होकर अच्छे तरीके से show हो जाए। ठीक है? एक अच्छी सी website बनाना है। Colorful भी हो और अच्छी हो। मतलब, सारे website में अच्छी website है। सही है?
